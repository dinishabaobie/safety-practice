在线使用：https://dinishabaobie.github.io/safety-practice/

- 300 道原题：126 单选、48 多选、126 判断，含 60 道原题解析
- 按题型、顺序或随机练习；错题复习、收藏
- 进度保存在当前浏览器本地，手机优先

纯静态页面，站点文件在 `dist/`，推送 `main` 后由 GitHub Actions 自动部署到 Pages。

Cloudflare Pages：输出目录 `dist`；构建命令留空，或填 `npm run build`（空操作）。
